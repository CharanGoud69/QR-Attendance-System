ClassLedger.
Your own attendance website.

Student ID/password login. No ChatGPT account needed.

Start on Windows

  1. Install Python 3.12 or later and enable Add Python to PATH.
  2. Extract this entire ZIP into a folder.
  3. Double-click START_WINDOWS.bat.
  4. Create sir’s admin ID and password when prompted. Password typing is hidden.
  5. Open http://localhost:8000 and sign in.

Keep the terminal window open while the website is in use.

Scan from a phone

  1. Connect the phone and laptop to the same Wi-Fi.
  2. Run ipconfig on the laptop and find its Wi-Fi IPv4 address.
  3. In the app’s Settings, enter http://YOUR-IP:8000.
  4. Check that this address loads on the phone.
  5. Add students, have them sign in and change their temporary passwords, then generate an IN QR.
  6. Download and send the QR to the representative. Generate a separate OUT QR at class end.

Each QR expires 10 minutes after generation. A localhost QR will not work from another device.

Use it from anywhere

Internet-wide use requires independent hosting with HTTPS and persistent storage. This package is ready to deploy, but does not itself create a live public website.

Separate laptop installations have separate records. Everyone must use the same hosted website to share one register.

Open README.md for backups, password recovery, hosting, and troubleshooting. The old ChatGPT Sites link remains a separate prototype.
